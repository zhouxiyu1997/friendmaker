# Friend Maker v1.0.0

## 中文

此版本基于当前主分支发布，统一桌面安装包和在线刷机站的版本号。

- 包含 v0.7.2 的自定义颜色明暗调整、选色超时保护和 PlatformIO Python 兼容修复。
- 改善串口确认解析，支持确认消息与 ESP-IDF 日志混在同一行的情况。
- 桌面打包从源码重建原生依赖，确保串口回调补丁进入安装包。
- 固件构建固定使用 Espressif32 7.0.0，与本次本地实机测试的构建平台保持一致。

### 下载和使用

- macOS：Apple Silicon 下载 `arm64` 安装包；Intel Mac 下载不带 `arm64` 的安装包。macOS 安装包经过签名和公证流程。
- Windows：下载 `win-x64.exe` 安装包；暂不支持 Windows ARM64。
- [在线刷机站](https://zhouxiyu1997.github.io/friendmaker/)默认提供 1.0.0 固件，请按 Switch 型号选择。
- 使用 ESP32-WROOM-32 / ESP-32S，刷写后重新连接手柄，再进行单步测试和绘制。

### 已知限制

本次本地 Switch 2 复测在开发板重启后能够运行，但此前出现的画笔或选色乱跳尚未定位根因，本版本不宣称已彻底修复。遇到异常时先停止任务、保存日志，再重启开发板并重新连接；测试时保持相同图片、时序参数和游戏菜单起点。

## English

This release aligns desktop installers and the online firmware flasher at version 1.0.0.

- Includes the custom-color, palette-timeout, and PlatformIO compatibility changes from v0.7.2.
- Recovers serial acknowledgements mixed with ESP-IDF logs.
- Builds native desktop dependencies from source so the serial callback patch is included.
- Pins the firmware platform to Espressif32 7.0.0, matching the platform used in local device testing.

Downloads cover signed and notarized macOS arm64/x64 builds and an unsigned Windows x64 installer. The online flasher provides firmware matched to the selected Switch model.

Intermittent brush/palette input errors have not been conclusively diagnosed. Local Switch 2 retesting worked after a board restart; this release does not claim that the underlying issue is resolved. Stop execution and save logs before restarting and reconnecting when an error occurs.
